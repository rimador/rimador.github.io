Programador de tuits

Els mateixos tuits que publicarien els bots, però per programar-los a mà a la web de X. Cada lot és un dia: la paraula del joc d'ahir i una paraula nàufraga aleatòria. Cada tuit només s'apunta a publicades quan tu confirmes que ja està programat.

Quan hagis acabat, puja els canvis: git add bot/publicades_*.json && git commit -m "Tuits programats" && git push
